# prompt-feld

Blendet über dem Chat-Eingabefeld ein eigenes Feld "Prompt-Optimierer" ein. Groben Entwurf hineintippen und Enter drücken: Der Entwurf wird zu einem klaren, vollständigen Prompt umgeschrieben und ins Chatfeld gesetzt, wo du ihn prüfen und abschicken kannst. Der Knopf "Text im Chatfeld optimieren" optimiert stattdessen das, was schon im Chatfeld steht. Die Aufgabe selbst wird dabei nicht ausgeführt.

## Installieren

Im Chatfeld einer Claude-Code-Sitzung (Desktop-App, Handy-App oder Terminal):

```
/plugin install prompt-feld --marketplace tojojuhem-cpu/prompt-feld-
```

Danach `y`, um den Marketplace hinzuzufügen, und einen Bereich wählen (z. B. für dich als Nutzer).

Oder aus einer Shell:

```
claude plugin install prompt-feld --marketplace tojojuhem-cpu/prompt-feld-
```

Das Feld erscheint über dem Chat-Eingabefeld in der Desktop-App, der Handy-App und im Terminal, nicht im Browser.
